# 简历写作规范

本文件提供简历文档的专门写作规范，应与基础规范（SKILL.md）结合使用。

**参考资料**：根据简历写作最佳实践和各大厂招聘要求整理而成。

## 适用范围

编写或编辑以下类型的简历文档时使用此规范：
- 个人简历
- 技术简历
- 求职简历
- 专业简历

## 简历结构规范

### 基本结构

简历应包含以下核心模块：

1. **个人信息**：姓名、联系方式、求职意向
2. **工作经历**：工作单位、职位、时间、主要职责和成果
3. **项目经验**：项目名称、角色、时间、技术栈、项目成果
4. **教育背景**：学校、专业、学历、时间
5. **专业技能**：技术能力、熟练程度、应用经验
6. **自我评价**：个人特点、职业优势（可选）

### 模块顺序建议

**技术岗位推荐顺序**：
个人信息 → 专业技能 → 项目经验 → 工作经历 → 教育背景 → 自我评价

**管理岗位推荐顺序**：
个人信息 → 工作经历 → 项目经验 → 管理经验 → 教育背景 → 自我评价

## 内容写作规范

### 个人信息

- **姓名**：使用真实姓名，字体稍大
- **联系方式**：包含邮箱、电话（可选）、求职意向
- **求职意向**：简洁明确，1-2 行描述期望职位

### 工作经历

#### 时间表示

- 使用统一的时间格式：`YYYY.MM - YYYY.MM` 或 `YYYY年M月 - YYYY年M月`
- 时间倒序排列，最近的经历放在前面
- 如果正在任职，结束时间写"至今"或"Present"

#### 单位和职位

- 公司名称使用全称
- 职位名称准确，符合行业习惯
- 如果是知名公司，可添加公司简介（1 行）

#### 职责和成果

- 使用"职责 + 成果"的结构
- 职责部分：3-5 点，简洁描述工作内容
- 成果部分：3-5 点，突出具体成果和价值

**示例**：
```
某互联网公司 | 资深后台开发工程师
2018.07 - 至今

主要职责：
- 负责电商平台的后端架构设计和开发
- 主导技术方案评审和代码审查
- 指导初中级工程师，提升团队技术水平

核心成果：
- 设计并实现高性能订单处理系统，支持 QPS 10万+
- 优化数据库查询性能，响应时间从 200ms 降低到 50ms
- 建立完善的监控和告警体系，系统可用性达到 99.9%
```

### 项目经验

#### 项目描述

- 项目名称：简洁准确
- 项目时间：`YYYY.MM - YYYY.MM`
- 项目角色：项目负责人、核心开发、参与开发等
- 技术栈：列举主要技术和框架

#### 项目内容

- **项目概述**：1-2 行说明项目目标和背景
- **个人职责**：3-5 点描述具体工作内容
- **项目成果**：3-5 点突出项目价值和影响

**示例**：
```
电商平台 | 项目负责人
2022.01 - 2023.06
技术栈：Java、Spring Boot、MySQL、Redis、Kafka

项目概述：
为某互联网生态打造的一站式商业化解决方案，支持百万级用户同时在线。

个人职责：
- 负责系统架构设计和技术选型
- 主导订单系统和支付系统的开发
- 设计分布式缓存和消息队列方案

项目成果：
- 平台上线后月营收超过 5000 万
- 系统稳定运行，故障率低于 0.01%
- 获得公司年度技术创新奖
```

### 专业技能

#### 技能分类

建议按以下方式分类：

1. **后端开发**：Java、Go、Python、Spring Boot、MyBatis 等
2. **前端开发**：React、Vue、TypeScript、Tailwind CSS 等
3. **数据库**：MySQL、PostgreSQL、MongoDB、Redis 等
4. **中间件**：Kafka、RabbitMQ、Elasticsearch 等
5. **云原生**：Docker、Kubernetes、云平台（阿里云、腾讯云等）
6. **其他**：DevOps、监控、性能优化等

#### 技能描述

- 使用"技术 + 熟练程度 + 应用经验"的结构
- 熟练程度：精通、熟练、掌握、了解
- 应用经验：结合项目说明使用场景

**示例**：
```
后端开发：
- Java：精通，多年大型项目开发经验
- Spring Boot：熟练，主导过多个微服务架构项目
- Go：掌握，用于高性能服务开发
- Python：了解，用于脚本和工具开发

数据库：
- MySQL：精通，优化过海量数据表性能
- Redis：熟练，设计过分布式缓存方案
- MongoDB：掌握，用于文档型数据存储

云原生：
- Docker：熟练，容器化部署经验
- Kubernetes：掌握，容器编排和管理
- 云平台：熟练，云上项目部署和维护
```

### 教育背景

- 按时间倒序排列
- 包含：学校名称、专业、学历、毕业时间
- 如有重要奖项或荣誉，可简要说明

**示例**：
```
某高校 | 计算机科学与技术 | 本科
2010.09 - 2014.06
```

### 自我评价

- 简洁突出个人优势和职业特点
- 使用"优势 + 证据"的结构
- 3-5 点为宜

**示例**：
```
- 多年后端开发经验，精通高并发、高可用系统设计
- 具备较强的架构设计和技术决策能力
- 良好的团队协作和项目管理经验
- 持续学习，跟进技术发展趋势
```

## 格式规范

### 字体和排版

- 正文字号：10-12 号
- 标题字号：递增，一级标题 16-18 号
- 行间距：1.2-1.5 倍
- 段落间距：0.5-1 行

### 列表使用

- 使用项目符号列举，每个要点独立成行
- 避免长段落，使用列表提高可读性
- 重要信息可加粗

### 数据和成果

- 尽量使用具体数字量化成果
- 提升百分比、节省时间、营收增长等
- 使用 QPS、响应时间、可用性等技术指标

## 注意事项

### 真实性

- 所有信息必须真实准确
- 成果应有具体项目或数据支撑
- 避免夸大和虚假表述

### 针对性

- 根据应聘岗位调整重点内容
- 技术岗位突出技术能力和项目经验
- 管理岗位突出管理经验和团队成果

### 简洁性

- 控制篇幅，1-2 页为宜
- 避免冗余信息
- 突出重点，去除无关经历

### 专业性

- 使用行业规范术语
- 技术名称准确无误
- 语法和标点正确
