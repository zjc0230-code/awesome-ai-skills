# 技术介绍文章写作规范

本文件提供技术介绍文章的专门写作规范，应与基础规范（SKILL.md）结合使用。

**参考资料**：根据技术博客和分享文章的写作最佳实践整理而成。

## 适用范围

编写或编辑以下类型的技术介绍文章时使用此规范：
- 技术博客文章
- 技术教程文章
- 技术分享文章
- 技术分析文章
- 技术趋势文章

## 文章结构规范

### 标准结构

技术介绍文章应包含以下部分：

1. **引言**：背景介绍、问题提出、阅读指引
2. **核心内容**：技术介绍、原理讲解、实现方法
3. **示例演示**：代码示例、实际应用
4. **总结**：要点总结、适用场景、后续展望
5. **参考资源**：相关文档、扩展阅读

### 各部分要求

#### 引言

- **背景介绍**：1-2 段说明技术背景和重要性
- **问题提出**：明确本文要解决的问题或探讨的技术点
- **阅读指引**：简要说明文章结构和适合的读者

#### 核心内容

- 按逻辑层次组织内容
- 使用标题、子标题清晰划分章节
- 每个段落聚焦一个主题
- 图文结合，增强可读性

#### 示例演示

- 代码示例应完整可运行
- 配合文字说明代码逻辑
- 重要部分添加注释
- 展示运行结果或效果

#### 总结

- 总结 3-5 个核心要点
- 说明技术的适用场景
- 指出技术的局限性
- 提供后续学习的方向

#### 参考资源

- 列举相关文档和资料
- 提供官方文档链接
- 推荐扩展阅读文章

## 内容写作规范

### 选题原则

- **有价值**：解决实际问题或提供新知识
- **有深度**：不仅描述"是什么"，更说明"为什么"和"怎么做"
- **有新意**：有独特见解或实践总结
- **可操作**：提供可落地的方案或代码

### 技术准确性

- 技术术语准确，避免错误表述
- 代码示例经过验证，可直接运行
- 版本信息明确，指明适用的技术版本
- 重要信息标注注意事项

### 逻辑清晰

- 内容层次分明，逻辑递进
- 概念到实践，从简到繁
- 避免跳跃式思维
- 使用过渡句连接段落

### 实用性

- 提供可操作的解决方案
- 包含完整的代码示例
- 给出最佳实践建议
- 分享踩坑经验和避坑指南

### 可读性

- 适当使用图表说明概念
- 代码示例简洁易懂
- 重要信息加粗强调
- 使用类比降低理解难度

## 格式规范

### 标题使用

- 使用递进的标题层级（二级、三级、四级）
- 标题简洁准确，反映内容主题
- 避免过长标题（超过 20 字）
- 使用数字编号或符号标识步骤

### 代码块

- 使用标准的代码块语法
- 指定语言类型以实现语法高亮
- 代码前有简短说明
- 代码内添加必要注释
- 长代码分段展示，分步说明

**示例**：

```javascript
// 创建一个简单的计数器
const counter = {
  count: 0,
  increment() {
    this.count++;
    console.log(this.count);
  }
};

// 使用计数器
counter.increment(); // 输出: 1
counter.increment(); // 输出: 2
```

### 列表使用

- 使用项目符号列举要点
- 列表项长度控制在 2 行以内
- 重要列表项使用加粗
- 避免列表过多嵌套（不超过 2 层）

### 图片和图表

- 截图清晰，标注重要信息
- 流程图简洁明了
- 架构图层次分明
- 图片下方添加说明文字

## 文章风格

### 语言风格

- 专业准确但不晦涩
- 适当使用行业术语
- 必要时对术语进行解释
- 避免过于口语化或网络用语

### 语气态度

- 客观中正
- 避免主观臆断
- 不夸大技术效果
- 承认技术的局限性

### 读者意识

- 明确目标读者群体
- 根据读者水平调整内容深度
- 提供不同层次的讲解
- 考虑读者可能遇到的问题

## 特殊类型文章

### 技术教程

- **目标明确**：清晰说明学习目标和适用人群
- **步骤详细**：每个步骤都有详细说明和截图
- **可验证**：每步完成后可以验证结果
- **完整案例**：提供完整的实战案例

### 技术分析

- **数据支撑**：使用测试数据或实验结果
- **对比分析**：横向对比不同技术方案
- **优缺点**：客观分析优劣
- **适用场景**：明确适用和不适用场景

### 技术趋势

- **数据来源**：引用可靠的数据和报告
- **时间维度**：分析过去、现在和未来
- **多角度**：从技术、市场、生态等角度分析
- **观点明确**：有清晰的观点和结论

## 质量检查

发布前检查以下要点：

- [ ] 标题准确反映内容
- [ ] 引言清晰说明文章目的
- [ ] 技术内容准确无误
- [ ] 代码示例可运行
- [ ] 逻辑清晰，层次分明
- [ ] 格式规范，排版美观
- [ ] 无错别字和语法错误
- [ ] 参考资源完整有效
- [ ] 字数合理（3000-8000 字）

## 注意事项

### 知识产权

- 引用他人内容注明出处
- 不直接复制粘贴他人文章
- 尊重知识产权，遵守许可协议

### 时效性

- 标注技术版本信息
- 定期更新过时内容
- 删除不再适用的建议

### 互动性

- 鼓励读者评论和反馈
- 回答读者的问题
- 根据反馈改进文章
