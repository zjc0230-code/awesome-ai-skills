# CodeBuddy Skills Collection

这是一个 CodeBuddy Skills 合集，包含多种实用的 AI 能力扩展。

## 安装方式

将需要的 skill 文件夹复制到 `~/.codebuddy/skills/` 目录下即可使用：

```bash
# 复制单个 skill
cp -r <skill-name> ~/.codebuddy/skills/

# 或复制所有 skills
cp -r * ~/.codebuddy/skills/
```

## 可用 Skills

| Skill | 描述 |
|-------|------|
| `algorithmic-art` | 使用 p5.js 创建算法艺术 |
| `brand-guidelines` | 应用 Anthropic 品牌样式指南 |
| `canvas-design` | 创建视觉艺术设计（海报、PNG、PDF） |
| `doc-coauthoring` | 文档协作编写工作流 |
| `docx` | Word 文档创建、编辑和分析 |
| `frontend-design` | 创建高质量前端界面 |
| `image-ocr` | 图片文字识别（OCR） |
| `internal-comms` | 内部沟通文档模板 |
| `mcp-builder` | MCP Server 开发指南 |
| `pdf` | PDF 文档操作工具包 |
| `pptx` | PowerPoint 演示文稿处理 |
| `skill-creator` | 创建自定义 Skill 指南 |
| `slack-gif-creator` | 创建 Slack 优化的 GIF 动画 |
| `theme-factory` | 主题样式工厂 |
| `web-artifacts-builder` | Web 组件构建工具 |
| `webapp-testing` | Web 应用测试工具（Playwright） |
| `xlsx` | Excel 电子表格处理 |

## 使用说明

安装后，在 CodeBuddy 对话中提及相关功能时，对应的 Skill 会自动激活并提供增强能力。
